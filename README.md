## 🚀 Quick Start (Run Locally)

Simply clone this repo and open `index.html`:

```bash
git clone https://github.com/evangelin-golda/personal-profile.git
cd personal-profile

# Open in browser directly, or serve locally:
npx serve .
# or
python -m http.server 8000
```

## 🌐 Deploy to GitHub Pages

1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. Navigate to your repository **Settings** ➔ **Pages**.
3. Under **Build and deployment** ➔ **Branch**, choose `main` and `/ (root)`.
4. Click **Save**. Your site will be published at:  
   `https://<your-username>.github.io/<your-repo-name>/`
